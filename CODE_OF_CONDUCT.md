# Code of conduct

Table, Bro follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful and constructive in issues, pull requests and every other space of the project.

Report unacceptable behavior to bro@table-bro.com. Every report is reviewed and kept confidential, and the maintainers
act on it as the Contributor Covenant describes in its enforcement guidelines.
