# Type Alias: BroCustomElementValueFn\<T\>

> **BroCustomElementValueFn**\<`T`\> = `object`\[`"valueFn"`\]

whose parameters TypeScript checks both ways, so a column of the application's rows, as BroCol\<Order\>, is a BroCol.
