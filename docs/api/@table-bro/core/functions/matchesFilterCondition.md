# Function: matchesFilterCondition()

> **matchesFilterCondition**(`fieldValue`, `condition`): `boolean`

Whether the value of a field meets a condition of a filter: every operator that the condition sets must match.

## Parameters

### fieldValue

`unknown`

the value of the field of the row

### condition

[`BroFilterCondition`](../interfaces/BroFilterCondition.md)\<`unknown`\>

the condition of the filter

## Returns

`boolean`
