# Function: registerSkin()

> **registerSkin**(`name`, `config`): `void`

Registers a skin under its name, for the config of the tables that name it in skin.

## Parameters

### name

[`BroSkin`](../type-aliases/BroSkin.md)

the name of the skin, as BroConfig.skin takes it

### config

[`BroSkinConfig`](../interfaces/BroSkinConfig.md)

the config of the skin

## Returns

`void`
